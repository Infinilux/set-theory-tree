# 集合论科技树（Set Theory Tech Tree）

把集合论 1872–2026 的发展做成一棵可漫游的**圆柱塔**：横截面按领域分扇区，
纵向按年代分层，节点是柏拉图立体（面数 = 重要度），高度即年份。

- 数据：**1485 条**（14 个时代 × 22 个领域）
- 交互：滚轮缩放 / 拖拽旋转 / 悬停看卡片 / 点图例筛选领域 / 按类型筛选 / 一键漫游
- 零后端，`vite build` 后是纯静态文件

## 快速开始

```bash
npm install
npm run dev        # 本地开发
npm run build      # 产出 dist/
npm run preview    # 预览构建结果
npm run validate   # 数据不变量校验（唯一的权威检查入口）
```

## 布局是怎么算出来的

`src/layout.ts` 里每个常量都带推导注释。三条关键约束：

**1. 层间距 `gap = min(36, 11 + n·0.32)`**
原型（为每层 81~876 条的数据调的）用 `min(42, 22 + n·0.08)`。本项目每层 8~194 条，
沿用原公式时低端几乎不起作用。实测改 `(11, 0.32)` 后层厚比值 3.5，视觉上「近代层更厚」才成立。

**2. 层半径 = 环形播种 + 松弛迭代**

只按面积反解半径会重叠（实测层内最近距离 1.45，需要 3.54）。改成两步：
① 按各领域在本层的占比分配角度、环形播种；
② 对距离小于 `SLOT = 2·1.5·1.18 = 3.54` 的节点对做 70 轮推开松弛，并把半径夹回环带。
实测 **14/14 层全部达到 3.54 间距，0 层重叠，0 节点越界**（见 `scripts/check-layout.ts`）。

**3. 塔的粗细比 `RADIUS_SCALE = 2.6`**

半径下限只保证「装得下」，直接用它塔会细成 10:1 的针（maxR 54.8 / 高 559）。
原型比例是 3.4:1。按 2.6 倍放大半径并收紧层间距后：**maxR 126.4 / 高 458 ≈ 3.6:1**。

**4. 漫游视场 `LEAD = 109 = 42 × RADIUS_SCALE`**
`fov = clamp(2·atan(1.1·R / LEAD), 45°, 125°)`。半径与 LEAD 同比例缩放，视场分布不变：
实测各层 45°~104°，14 层里只有 1 层触下限，视场呼吸保留。

## 年份可信度

每个条目都带 `year_basis`：

| 等级 | 占比 | 含义 |
|---|---|---|
| `exact` | 85%+ | 有明确发表/成文年 |
| `circa` | ~15% | 约、跨年、渐进成形（如「某人某年工作」类） |
| `scholarly_disputed` | <1% | 学界对优先权有争议 |

许多成果有**公告年与发表年之分**（Easton 1964/1970、Martin–Steel 1985/1989、Scott 1961/1967），
本项目把这类情况**拆成两个独立条目**，而不是二选一。
